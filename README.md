# SayemMobileApp

SayemMobileApp is a Progressive Web Application (PWA) designed to help shop owners collect and manage customer data easily. The app simplifies record keeping and makes customer information accessible from mobile devices.

## Features
- Customer data collection
- Simple data management system
- Mobile-friendly interface
- Installable PWA
- Fast and lightweight

## Use Case
Small shop owners often store customer information manually. This web app digitizes the process so records can be managed easily and accessed anytime.

## Tech Stack
- HTML
- CSS
- JavaScript
- Progressive Web App (PWA)

## Goal
The goal of this project is to provide a simple digital solution for shop owners to manage customer records efficiently.

## Future Improvements
- Search and filtering for customer records
- Cloud data storage
- Authentication system
- Analytics dashboard
